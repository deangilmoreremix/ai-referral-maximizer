# Welcome to AI Sales Maximizer Storybook

This Storybook is a UI component explorer for the AI Sales Maximizer application. It's a great way to view and test UI components in isolation.

## Available Components

The following components are available in this Storybook:

- **ContentCard**: Cards displaying different content types
- **DaySelector**: Component for selecting days in multi-day content plans
- **DocumentModal**: Modal for downloading documents
- **FeatureTooltip**: Contextual tooltips for features
- **ModelSelector**: Interface for selecting AI models
- **OnboardingTour**: Guided tour for new users
- **PersonalizerModal**: Settings for content personalization
- **WelcomeModal**: Modal that greets first-time users

## How to use this Storybook

1. Browse the components in the sidebar
2. View each component in isolation
3. Interact with the components and change their properties using the Controls panel
4. View different states and variants of each component
